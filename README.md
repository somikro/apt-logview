#### Debian APT Log Viewer (apt-logview)

A lightweight Python command-line utility designed to clean up the visual clutter from raw Debian APT terminal logs (`/var/log/apt/term.log`). It strips out repetitive interactive progress bars, percentage loop spam, and database reading counters while offering options to keep or remove ANSI color codes.

Perfect for system administrators and engineers who need to audit major distribution upgrades or archive cleanly formatted logs.

#### Features

-   **Multi-Session Detection:** Automatically identifies and lists all apt sessions in `/var/log/apt/term.log` (marked by `Log started:` and `Log ended:` timestamps).
-   **Interactive Session Selection:** Displays a menu of all sessions with summary information (start/end times, number of affected packages) and lets you choose which one to process.
-   **Non-Interactive Mode:** Use the `-s` flag to select a specific session directly without the menu.
-   **Progress Spam Removal:** Deletes thousands of inline lines generated by `\r` cursor rewrites (e.g., `Unpacking... (10%)... (20%)`).
-   **Database Sequence Trimming:** Automatically filters out verbose blocks starting with `(Reading database ...`.
-   **ANSI Color Control:** Offers a switch to preserve color codes for terminal reading or strip them completely for standard text editors.
-   **Clean Terminal Exit:** Handles buffer flushing properly to guarantee a clean hand-off back to your shell prompt.

#### Installation

Since the script relies entirely on standard Python 3 modules, no external dependencies are required.

1.  Copy the script code into a file named `apt-logview.py`.
2.  Make the script executable:

    ```
    chmod +x apt-logview.py
    ```

3.  (Optional) Move it to a directory in your `$PATH` for system-wide access:

    ```
    sudo mv apt-logview.py /usr/local/bin/apt-logview
    ```

#### Usage & Arguments

```
usage: apt-logview.py [-h] [-i INPUT] [-o OUTPUT] [-c] [-s SESSION]

Sanitize Debian APT terminal logs by removing progress spam and database reading sequences.

options:
  -h, --help                    show this help message and exit
  -i INPUT, --input INPUT       Path to the raw input log file. If omitted, uses /var/log/apt/term.log.
  -o OUTPUT, --output OUTPUT    Path to the output file. If omitted, outputs directly to stdout.
  -c, --color                   Keep ANSI escape/color codes intact for reading via 'less -R'.
  -s SESSION, --session SESSION Select session by number (1-based). If omitted, shows interactive menu.
```



#### Examples

#### 1\. Interactive Session Selection Menu

Run without arguments to see all apt sessions and choose one interactively:

```
./apt-logview.py
```

#### 2\. Direct Session Selection (Non-Interactive)

Process session #2 directly without the menu:

```
./apt-logview.py -s 2 -o ~/session2_plaintext.log
```

#### 3\. Convert to Plain Text File (For standard text editors)

Reads session interactively, strips all formatting/spam, and writes a clean text file:

```
./apt-logview.py -o ~/upgrade_plaintext.log
```

#### 4\. Keep Colors for Terminal Reading

Preserves the original red, green, and bold warnings with interactive session selection:

```
./apt-logview.py -c | less -R
```

Or use a specific session directly:

```
./apt-logview.py -s 3 -c | less -R
```

#### 5\. Processing Custom Log Files

Analyze a custom apt log file:

```
./apt-logview.py -i /path/to/custom/apt.log -s 1 -o ~/output.log
```
