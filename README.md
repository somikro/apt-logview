#### Debian APT Log Viewer (apt-logview)

A lightweight Python command-line utility designed to clean up the visual clutter from raw Debian APT terminal logs (`/var/log/apt/term.log`). It strips out repetitive interactive progress bars, percentage loop spam, and database reading counters while offering options to keep or remove ANSI color codes.

Perfect for system administrators and engineers who need to audit major distribution upgrades or archive cleanly formatted logs.

#### Features

-   **Progress Spam Removal:** Deletes thousands of inline lines generated by `\r` cursor rewrites (e.g., `Unpacking... (10%)... (20%)`).
-   **Database Sequence Trimming:** Automatically filters out verbose blocks starting with `(Reading database ...`.
-   **ANSI Color Control:** Offers a switch to preserve color codes for terminal reading or strip them completely for standard text editors.
-   **Flexible I/O Streams:** Seamlessly switches between files and standard Unix streams (`stdin` / `stdout`).
-   **Clean Terminal Exit:** Handles buffer flushing properly to guarantee a clean hand-off back to your shell prompt.

#### Installation

Since the script relies entirely on standard Python 3 modules, no external dependencies are required.

1.  Copy the script code into a file named `clean_log.py`.
2.  Make the script executable:



    ```
    chmod +x clean_log.py
    ```


3.  (Optional) Move it to a directory in your `$PATH` for system-wide access:



    ```
    sudo mv clean_log.py /usr/local/bin/apt-clean-log
    ```

* * *

#### Usage & Arguments



```
usage: clean_log.py [-h] [-i INPUT] [-o OUTPUT] [-c]

Sanitize Debian APT terminal logs by removing progress spam and database reading sequences.

options:
  -h, --help                    show this help message and exit
  -i INPUT, --input INPUT       Path to the raw input log file. If omitted, reads from stdin.
  -o OUTPUT, --output OUTPUT    Path to the output file. If omitted, outputs directly to stdout.
  -c, --color                   Keep ANSI escape/color codes intact for reading via 'less -R'.
```



#### Examples

#### 1\. Convert to Plain Text File (For standard text editors)

Reads the default system log, strips all formatting/spam, and writes a clean text file:


```
./clean_log.py -o ~/stage1_plaintext.log
```



#### 2\. Keep Colors for Terminal Reading

Preserves the original red, green, and bold warnings, sending the clean stream straight into `less`:


```
./clean_log.py -c | less -R
```



#### 3\. Processing Compressed Log Archives (`.gz`)

Passes archived logs directly via a pipe using standard input:


```
zcat /var/log/apt/term.log.1.gz | ./clean_log.py -c -o ~/archived_colored.log
```



#### 4\. Real-time Sanitization During an Upgrade

Sanitize and save the output of a live full distribution upgrade on the fly:


```
sudo apt full-upgrade 2>&1 | ./clean_log.py -c -o ~/stage2_upgrade.log
```
